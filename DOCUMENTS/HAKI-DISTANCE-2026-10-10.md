# Хаки: DISTANCE и защита после поражения

10.10.2026, 17:11 Asia/Yekaterinburg (UTC+05:00; 12:11 UTC).
Музроб, бот `6603c7b8-f81d-4309-b4cf-28e3f9a6c670`.
Основа: `8ca2c99`, включая PR #16 Бориса. Изменения относятся только к Хаки,
его запуску, тестам и документации. Общие классы и профиль Нагибатора не изменены.

## Причина

В матче https://hackathon.no-offence.ru/matches/54dfe361-0f43-4e35-b396-c2252e7a7f00
Хаки после 46 выстрелов оставил две одиночки среди 21 допустимой клетки.
Последующие шесть промахов не были техническим сбоем; реальные цели H2/J2.
Соперник использовал SONAR и SHIELD. Хаки не имел выбранных бонусов.

Исторический профиль соперника показывал 71% краевых дебютных выстрелов, в этой
партии их было 20%. В новом PR Бориса также описано 9 поражений из 10 при защите
по краям против адаптирующихся команд. Это результат команды, не повторённый
в этой работе эксперимент. Он меняет приоритет: не превращать прошлый дебют
соперника в предсказуемую постоянную расстановку.

## Новое поведение

- Против команд флот случайный. Выбор «всё к краям / всё внутрь» по старому
  профилю отключён именно у Хаки. Встроенные соперники сохраняют общий план.
  Отдельная свежая разведка по модификаторам пока не реализована; при её отсутствии
  не выдаём старые смешанные данные за актуальные.
- Сохраняются карта вероятностей, добивание, повтор выстрела после SHIELD,
  общий точный перебор до двух кораблей и ограниченный собственный перебор одиночек.
- Подключён DISTANCE по алгоритму информационного запроса из общей основы Бориса.
  Ответы сервера восстанавливаются из `bonus_results`, включая `requestedCell`;
  нулевое расстояние учитывается. Невалидный/пустой ответ не интерпретируется
  как расстояние, но учитывается в ограничении числа запросов.
- До двух запросов за матч, только при доступном остатке DISTANCE у сервера.
  Запрос возможен в точной концовке до двух кораблей, без недобитых попаданий,
  при информативности не менее 0,5 бита. При отсутствии подходящих конфигураций
  продолжается стрельба.
- Сохраняется последний выстрел лимита. Если известно, что цело больше 55%
  нашего флота, бонус не тратится. Это эвристика экономии, а не гарантия победы.
  При остатке вычислительного бюджета менее 50 мс новый запрос не планируется.
- Мины, SONAR, SALVO и SHIELD Хаки не применяет. Он не наследует бонусный класс
  Бориса, поэтому включение мин у того не включает их у Хаки.

## Настройки и запуск

В кабинете изменён только Хаки: DISTANCE = 2; остальные бонусы = 0.
Отображаемая цена DISTANCE — 1 очко за применение, лимит платформы — 3.
Стратегия ограничена двумя запросами: до 2 очков прямой стоимости за матч.
Настройки сохранены, бот остаётся не в сети. Токены не читались и не менялись.

`scripts/run-haki.ps1` теперь передаёт `--allow-bonuses` только своему запуску.
Обычный сценарий: TRAINING/EASY → три победы → RANKING. Первое поражение
останавливает процесс. Явный `-Mode RANKING` сохраняется для подтверждённой
паузы тренировок. Новые правила берутся из MATCH_STARTED, а не из этого документа.

Ручной эквивалент: добавить `--allow-bonuses` к прежней команде с
`--strategy battleships.strategies.haki:HakiObservationBot --stop-on-loss`.
Без флага оболочка не разрешит бонус. Если сервер не выдаст DISTANCE, Хаки
продолжит обычную стрельбу. Публикация кода не запускает процесс.

## Проверка эффективности

`python scripts/benchmark_haki_distance.py` воспроизводит позицию после 46-го
выстрела. Публичная обезличенная позиция сохранена в `tests/haki_endgame_position.json`.
Тест использует реальный контракт `HakiObservationBot`, проверяет допустимость
каждого действия, списание запросов и лимит в два применения.

| Набор позиций | Без DISTANCE: оставшиеся выстрелы | С DISTANCE: выстрелы + запросы |
|---|---:|---:|
| Настоящие H2/J2, 100 seed | 18,85 | 2,66 + 2 |
| Все 194 совместимые пары, один seed на пару | 14,54 | 5,68 + 2 |

Это 588 завершённых прогонов концовки. Второй набор уменьшает зависимость от
одной удачной пары клеток, но остаётся проверкой одной геометрии доступного поля.
Запросы списывают лимит выстрелов и очки, поэтому показаны отдельно.
Не моделировались ответные ходы противника, рост Elo и изменения поведения
соперников. Эти числа не являются прогнозом турнирных побед.

Дополнительно проверяются пределы расходов, нулевой и неверный ответ, отсутствие
бонусов, сохранение последнего выстрела, добивание после щита и работа в процессе
оболочки с бюджетом 150 мс. Платформенный матч с DISTANCE ещё не сыгран.

Полный локальный набор: 107 тестов, все прошли (Windows, Python 3.12).
Работа выполнена в отдельном checkout; несовместимые с Windows имена чужих
документов в текущем main исключены из локального checkout и не переименованы.
