# Справочник протокола бота

Сгенерирован из `GET /api/v1/documentation/protocol` платформы хакатона 2026-10-10. Знак `?` после типа — значение может быть `null`. Протокол только расширяется: незнакомые поля, сообщения и значения перечислений бот должен пропускать.

Подключение: WebSocket `wss://hackathon.no-offence.ru/api/v1/bots/connection`, заголовок `Authorization: Bearer <токен бота>`.

## Команды: бот → платформа

### `CHANGE_MODE`

Смена режима бота; действует со следующего матча

| Поле | Тип | Описание |
|---|---|---|
| `mode` | `string` | Имя режима; неизвестное имя отклоняется ответом, а не разрывом соединения |
| `opponent` | `string?` | Уровень встроенного бота — соперника в тренировке, имя значения BuiltInBot; читается только при mode = TRAINING, без поля — EASY |

```json
{"type": "CHANGE_MODE", "mode": "TRAINING", "opponent": "MEDIUM"}
```

### `PLACE`

Расстановка кораблей в идущей партии бота

| Поле | Тип | Описание |
|---|---|---|
| `ships` | `list[ShipDto]` | Корабли расстановки |

```json
{"type": "PLACE", "ships": [{"cells": [{"row": 0, "column": 0}, {"row": 0, "column": 1}, {"row": 0, "column": 2}, {"row": 0, "column": 3}]}, {"cells": [{"row": 0, "column": 5}, {"row": 0, "column": 6}, {"row": 0, "column": 7}]}, {"cells": [{"row": 2, "column": 0}, {"row": 2, "column": 1}, {"row": 2, "column": 2}]}, {"cells": [{"row": 2, "column": 4}, {"row": 2, "column": 5}]}, {"cells": [{"row": 4, "column": 0}, {"row": 4, "column": 1}]}, {"cells": [{"row": 6, "column": 0}, {"row": 7, "column": 0}]}, {"cells": [{"row": 4, "column": 3}]}, {"cells": [{"row": 4, "column": 5}]}, {"cells": [{"row": 4, "column": 7}]}, {"cells": [{"row": 4, "column": 9}]}]}
```

### `SHOOT`

Выстрел в идущей партии бота

| Поле | Тип | Описание |
|---|---|---|
| `cell` | `CellDto` | Клетка выстрела; любая пара целых чисел, в том числе вне поля |

```json
{"type": "SHOOT", "cell": {"row": 2, "column": 1}}
```

### `USE_BONUS`

Применение бонуса в свой ход; ответ — BONUS_RESOLVED или BONUS_REJECTED

| Поле | Тип | Описание |
|---|---|---|
| `bonus` | `Bonus` | Бонус |
| `cell` | `CellDto?` | Клетка: для DISTANCE и SONAR — клетка поля соперника, для MINE — клетка своего поля; для SALVO и SHIELD не читается, можно не присылать |

```json
{"type": "USE_BONUS", "bonus": "SONAR", "cell": {"row": 4, "column": 4}}
```

### `PLACE_BET`

Ставка «Казино „Рояль“» в ответ на BET_REQUESTED: модификатор, с которым бот хочет играть, и размер ставки

| Поле | Тип | Описание |
|---|---|---|
| `modifier` | `RuleModifier` | Модификатор, на который бот ставит |
| `amount` | `number` | Размер ставки в очках рейтинга |

```json
{"type": "PLACE_BET", "modifier": "DUEL", "amount": 15.0}
```

## Сообщения: платформа → бот

### `MATCH_STARTED`

Партия началась: набор правил, бонусы обеих сторон, соперник и запрос расстановки

| Поле | Тип | Описание |
|---|---|---|
| `rules` | `RulesResponse` | Набор правил партии |
| `bonuses` | `list[BonusUsesDto]` | Бонусы бота в партии с числом использований; бонуса, которого нет в списке, у бота нет; пустой список — бонусов нет |
| `opponent` | `BotMessageMatchStartedOpponent` | Соперник в партии |

```json
{"type": "MATCH_STARTED", "rules": {"columns": 10, "rows": 10, "fleet": [{"length": 4, "count": 1}, {"length": 3, "count": 2}, {"length": 2, "count": 3}, {"length": 1, "count": 4}], "touchRule": "NO_TOUCHING_EVEN_DIAGONALLY", "turnAfterHitRule": "SHOOTER_KEEPS_TURN", "matchDurationSeconds": 210, "shotLimitPerPlayer": 100, "moveTimeoutSeconds": 1, "placementWindowSeconds": 10, "modifier": null, "shotsPerTurn": 1}, "bonuses": [{"bonus": "SONAR", "uses": 2}, {"bonus": "SHIELD", "uses": 1}], "opponent": {"kind": "REMOTE_BOT", "botId": "3f2b8c1e-6a4d-4f0b-9c5e-2d7a1b8e4c90", "teamName": "Kraken", "builtInBot": null, "bonuses": [{"bonus": "SALVO", "uses": 1}]}}
```

### `PLACEMENT_ACCEPTED`

Расстановка принята и окончательна

Полей нет.

```json
{"type": "PLACEMENT_ACCEPTED"}
```

### `PLACEMENT_REJECTED`

Расстановка отклонена; можно прислать другую

| Поле | Тип | Описание |
|---|---|---|
| `reason` | `RejectionReason` | Причина отказа |

```json
{"type": "PLACEMENT_REJECTED", "reason": "SHIPS_TOUCH"}
```

### `TURN_REQUESTED`

Ход бота: ждём одно действие — SHOOT или USE_BONUS. Следующее действие бот присылает только после ответа на это: каждое следующее действие того же хода запрашивает новый TURN_REQUESTED — после попадания, после BONUS_RESOLVED. Время на ход (moveTimeoutSeconds) отсчитывается от каждого запроса заново

| Поле | Тип | Описание |
|---|---|---|
| `moveNumber` | `integer` | Номер хода в партии, общий для обоих игроков |
| `shotsLeft` | `integer` | Сколько выстрелов у бота осталось |
| `shotsLeftInTurn` | `integer` | Сколько выстрелов осталось в текущем ходу; бонус его не меняет — после BONUS_RESOLVED приходит прежнее значение, после SALVO — shotsInTurn залпа |

```json
{"type": "TURN_REQUESTED", "moveNumber": 7, "shotsLeft": 97, "shotsLeftInTurn": 1}
```

### `SHOT_RESOLVED`

Результат выстрела бота

| Поле | Тип | Описание |
|---|---|---|
| `cell` | `CellDto` | Клетка выстрела в том виде, в каком бот её прислал |
| `result` | `ShotResult` | Результат выстрела |

```json
{"type": "SHOT_RESOLVED", "cell": {"row": 2, "column": 1}, "result": "HIT"}
```

### `SHOT_REJECTED`

Выстрел бота отклонён

| Поле | Тип | Описание |
|---|---|---|
| `cell` | `CellDto` | Клетка выстрела в том виде, в каком бот её прислал |
| `reason` | `RejectionReason` | Причина отказа |

```json
{"type": "SHOT_REJECTED", "cell": {"row": 2, "column": 1}, "reason": "NOT_YOUR_TURN"}
```

### `OPPONENT_SHOT`

Выстрел соперника по полю бота

| Поле | Тип | Описание |
|---|---|---|
| `cell` | `CellDto` | Клетка выстрела в том виде, в каком соперник её прислал |
| `result` | `ShotResult` | Результат выстрела |

```json
{"type": "OPPONENT_SHOT", "cell": {"row": 5, "column": 6}, "result": "MISS"}
```

### `MATCH_FINISHED`

Партия завершена

| Поле | Тип | Описание |
|---|---|---|
| `outcome` | `PlayerOutcome` | Итог партии для бота |
| `endReason` | `MatchEndReason` | Причина завершения |

```json
{"type": "MATCH_FINISHED", "outcome": "WIN", "endReason": "FLEET_DESTROYED"}
```

|---|---|---|


Ход соперника не сделан за время на ход и засчитан промахом

### `MATCH_SNAPSHOT`

Состояние идущей партии; первое сообщение нового соединения бота, у которого идёт партия

| Поле | Тип | Описание |
|---|---|---|
| `rules` | `RulesResponse` | Набор правил партии |
| `ships` | `list[ShipDto]?` | Принятая расстановка бота; null, пока расстановка не принята; в «Спидране» всегда null: флот расставляет платформа |
| `shots` | `list[BotMessageMatchSnapshotShot]` | Принятые выстрелы бота по порядку, клетки в том виде, в каком бот их прислал |
| `opponentShots` | `list[BotMessageMatchSnapshotShot]` | Принятые выстрелы соперника по полю бота по порядку |
| `shotsLeft` | `integer` | Сколько выстрелов у бота осталось |
| `placementWindowLeftSeconds` | `integer?` | Остаток окна расстановки в целых секундах, округлённый вниз, пока партия в расстановке: 0 — окно ещё открыто, но осталось меньше секунды; null — партия уже не в расстановке |
| `bonuses` | `list[BonusUsesDto]` | Остаток использований каждого бонуса, который был у бота на старте партии; пустой список — бонусов не было |
| `shieldActive` | `boolean` | Активен ли щит бота |
| `mines` | `list[CellDto]` | Клетки мин бота, которые ещё не сработали; сработавшая мина видна в opponentShots с результатом MINE |

```json
{"type": "MATCH_SNAPSHOT", "rules": {"columns": 10, "rows": 10, "fleet": [{"length": 4, "count": 1}, {"length": 3, "count": 2}, {"length": 2, "count": 3}, {"length": 1, "count": 4}], "touchRule": "NO_TOUCHING_EVEN_DIAGONALLY", "turnAfterHitRule": "SHOOTER_KEEPS_TURN", "matchDurationSeconds": 210, "shotLimitPerPlayer": 100, "moveTimeoutSeconds": 1, "placementWindowSeconds": 10, "modifier": null, "shotsPerTurn": 1}, "ships": [{"cells": [{"row": 0, "column": 0}, {"row": 0, "column": 1}, {"row": 0, "column": 2}, {"row": 0, "column": 3}]}, {"cells": [{"row": 0, "column": 5}, {"row": 0, "column": 6}, {"row": 0, "column": 7}]}, {"cells": [{"row": 2, "column": 0}, {"row": 2, "column": 1}, {"row": 2, "column": 2}]}, {"cells": [{"row": 2, "column": 4}, {"row": 2, "column": 5}]}, {"cells": [{"row": 4, "column": 0}, {"row": 4, "column": 1}]}, {"cells": [{"row": 6, "column": 0}, {"row": 7, "column": 0}]}, {"cells": [{"row": 4, "column": 3}]}, {"cells": [{"row": 4, "column": 5}]}, {"cells": [{"row": 4, "column": 7}]}, {"cells": [{"row": 4, "column": 9}]}], "shots": [{"cell": {"row": 4, "column": 4}, "result": "MISS"}], "opponentShots": [{"cell": {"row": 0, "column": 0}, "result": "HIT"}, {"cell": {"row": 1, "column": 1}, "result": "MISS"}], "shotsLeft": 99, "placementWindowLeftSeconds": null, "bonuses": [{"bonus": "SONAR", "uses": 1}, {"bonus": "SHIELD", "uses": 0}], "shieldActive": true, "mines": [{"row": 9, "column": 9}]}
```

| Поле | Тип | Описание |
|---|---|---|
| `mode` | `string` | Имя режима в том виде, в каком бот его прислал |
| `reason` | `BotCommandRejectionReason` | Причина отказа |

```json
{"type": "MODE_REJECTED", "mode": "TOURNAMENT", "reason": "UNKNOWN_MODE"}
```

### `COMMAND_REJECTED`

Команда бота отклонена и не выполнена; соединение остаётся открытым

| Поле | Тип | Описание |
|---|---|---|
| `command` | `BotCommandType?` | Вид отклонённой команды; null, когда сообщение не читается или его тип неизвестен |
| `reason` | `BotCommandRejectionReason` | Причина отказа |


### `BONUS_RESOLVED`

Бонус применён; ход он не передаёт. Следом приходит новый TURN_REQUESTED того же хода с прежним shotsLeftInTurn (после SALVO — shotsInTurn), и время на ход отсчитывается от него заново. Если бонус потратил последний выстрел лимита, ход переходит к сопернику: TURN_REQUESTED получает соперник. Заполнено только поле применённого бонуса, остальные null

| Поле | Тип | Описание |
|---|---|---|
| `bonus` | `Bonus` | Применённый бонус |
| `distance` | `integer?` | DISTANCE: расстояние от клетки до ближайшей клетки непотопленного корабля соперника, \|Δrow\| + \|Δcolumn\|; 0 — в клетке корабль |
| `count` | `integer?` | SONAR: число клеток кораблей соперника, подбитые тоже, в квадрате 3 × 3 с центром в клетке, без части за краем поля |
| `shotsInTurn` | `integer?` | SALVO: сколько выстрелов в ходе после залпа |
| `shieldActive` | `boolean?` | SHIELD: щит активен — true |
| `mineCell` | `CellDto?` | MINE: клетка поставленной мины |

```json
{"type": "BONUS_RESOLVED", "bonus": "SONAR", "distance": null, "count": 2, "shotsInTurn": null, "shieldActive": null, "mineCell": null}
```

### `OPPONENT_BONUS_USED`

Соперник применил бонус; клетка и результат не раскрываются. В «Птичьем коробе» не приходит

| Поле | Тип | Описание |
|---|---|---|
| `bonus` | `Bonus` | Применённый соперником бонус |

```json
{"type": "OPPONENT_BONUS_USED", "bonus": "SHIELD"}
```

### `BONUS_REJECTED`

Бонус не применён, партия не изменилась: использования, выстрелы, ход и его время прежние, соперник ничего не получает. Нового TURN_REQUESTED нет: пока не истекло время хода, бот может прислать другое действие

| Поле | Тип | Описание |
|---|---|---|
| `bonus` | `Bonus` | Бонус в том виде, в каком бот его прислал |
| `reason` | `BonusRejectionReason` | Причина отказа |

```json
{"type": "BONUS_REJECTED", "bonus": "SONAR", "reason": "BONUS_NOT_AVAILABLE"}
```

### `BET_REQUESTED`

Приглашение к ставке «Казино „Рояль“» перед партией: бот ставит рейтинг на модификатор, с которым хочет играть. Ставки закрыты, выигрывает бо́льшая; итог — в BETTING_FINISHED, затем MATCH_STARTED. Бот, который ещё не поставил и переподключился до конца торгов, получает приглашение снова — с оставшимся временем

| Поле | Тип | Описание |
|---|---|---|
| `modifiers` | `list[RuleModifier]` | Модификаторы, на которые можно ставить |
| `maxAmount` | `number` | Наибольшая ставка бота в очках рейтинга |
| `betWindowSeconds` | `integer` | Время на ставку в целых секундах от приглашения |

```json
{"type": "BET_REQUESTED", "modifiers": ["DUEL", "THREE_MUSKETEERS", "SPEEDRUN"], "maxAmount": 40.5, "betWindowSeconds": 5}
```

### `BET_ACCEPTED`

Ставка принята. Бот, переподключившийся во время торгов после принятой ставки, получает его снова: ставка в силе

| Поле | Тип | Описание |
|---|---|---|
| `modifier` | `RuleModifier` | Модификатор ставки |
| `amount` | `number` | Размер ставки в очках рейтинга |

```json
{"type": "BET_ACCEPTED", "modifier": "DUEL", "amount": 15.0}
```

### `BET_REJECTED`

Ставка отклонена и не учтена; соединение остаётся открытым

| Поле | Тип | Описание |
|---|---|---|
| `modifier` | `RuleModifier` | Модификатор в том виде, в каком бот его прислал |
| `amount` | `number` | Размер ставки в том виде, в каком бот его прислал |
| `reason` | `BetRejectionReason` | Причина отказа |

```json
{"type": "BET_REJECTED", "modifier": "DUEL", "amount": 15.0, "reason": "BETTING_CLOSED"}
```

### `BETTING_FINISHED`

Торги «Казино „Рояль“» завершены; следом приходит MATCH_STARTED, в наборе правил которого выигравший модификатор. Ставка соперника не раскрывается

| Поле | Тип | Описание |
|---|---|---|
| `modifier` | `RuleModifier?` | Выигравший модификатор; null — торги не выбрали ни одного |
| `betWon` | `boolean` | Выиграла ли ставка бота; false и тогда, когда бот не ставил |

```json
{"type": "BETTING_FINISHED", "modifier": "DUEL", "betWon": true}
```

## Типы

### `BonusUsesDto`

Бонус и число его использований

| Поле | Тип | Описание |
|---|---|---|
| `bonus` | `Bonus` | Бонус |
| `uses` | `integer` | Число использований |

### `BotMessageMatchSnapshotShot`

Выстрел в снимке партии

| Поле | Тип | Описание |
|---|---|---|
| `cell` | `CellDto` | Клетка выстрела в том виде, в каком её прислал стрелявший |
| `result` | `ShotResult` | Результат выстрела |

### `BotMessageMatchStartedOpponent`

Соперник в партии: бот команды или встроенный бот платформы

| Поле | Тип | Описание |
|---|---|---|
| `kind` | `PlayerKind` | Тип соперника |
| `botId` | `uuid?` | Идентификатор бота команды соперника; null у встроенного бота |
| `teamName` | `string?` | Имя команды соперника; null у встроенного бота |
| `builtInBot` | `BuiltInBot?` | Уровень встроенного бота; null у бота команды |
| `bonuses` | `list[BonusUsesDto]` | Бонусы соперника в партии с числом использований на старте; пустой список — бонусов нет |

### `CellDto`

Клетка поля в том виде, в каком её прислали; может лежать вне поля

| Поле | Тип | Описание |
|---|---|---|
| `row` | `integer` | Строка, отсчёт от 0 |
| `column` | `integer` | Столбец, отсчёт от 0 |

### `RulesResponse`

Набор правил партии, зафиксированный на её старте

| Поле | Тип | Описание |
|---|---|---|
| `columns` | `integer` | Число столбцов поля |
| `rows` | `integer` | Число строк поля |
| `fleet` | `list[RulesResponseShipClass]` | Состав флота: классы кораблей по длине |
| `touchRule` | `TouchRule` | Правило касания кораблей |
| `turnAfterHitRule` | `TurnAfterHitRule` | Правило очерёдности хода после попадания |
| `matchDurationSeconds` | `integer` | Длительность партии в секундах |
| `shotLimitPerPlayer` | `integer` | Лимит выстрелов каждого игрока |
| `moveTimeoutSeconds` | `integer` | Время на ход в целых секундах от запроса хода; не уложился — ход засчитывается промахом |
| `placementWindowSeconds` | `integer` | Окно расстановки в секундах от старта партии; без принятой расстановки к его концу — техническое поражение |
| `modifier` | `RuleModifier?` | Модификатор партии; null — обычные правила без модификатора |
| `shotsPerTurn` | `integer` | Выстрелов в ходе: сколько выстрелов игрок делает, пока ход не перейдёт к сопернику; тратит ли выстрел хода попадание — turnAfterHitRule |

### `RulesResponseShipClass`

Класс кораблей флота

| Поле | Тип | Описание |
|---|---|---|
| `length` | `integer` | Длина корабля в клетках |
| `count` | `integer` | Число кораблей этой длины |

### `ShipDto`

Корабль расстановки

| Поле | Тип | Описание |
|---|---|---|
| `cells` | `list[CellDto]` | Клетки корабля |

## Перечисления

### `BetRejectionReason`

Причина, по которой платформа не приняла ставку

| Значение | Смысл |
|---|---|
| `BETTING_CLOSED` | Ставка сейчас не принимается: бот не приглашён к ставке или время на ставку вышло |
| `MODIFIER_NOT_AVAILABLE` | На этот модификатор ставить нельзя: его нет в приглашении |
| `INVALID_AMOUNT` | Недопустимый размер ставки: не положительный или больше maxAmount из приглашения |

### `Bonus`

Бонус: действие бота в свой ход командой USE_BONUS

| Значение | Смысл |
|---|---|
| `DISTANCE` | «Расстояние»: расстояние от указанной клетки до ближайшей клетки непотопленного корабля соперника; нужна клетка, тратит выстрел из лимита |
| `SONAR` | «Сонар»: сколько клеток кораблей соперника в квадрате 3 × 3 с центром в указанной клетке; нужна клетка, тратит выстрел из лимита |
| `SALVO` | «Залп»: до конца хода 3 выстрела, попадание выстрел хода не тратит; выстрела из лимита не тратит |
| `SHIELD` | «Щит»: отбивает следующее попадание по флоту бота — результат DEFENDED; одновременно активен один щит; тратит выстрел из лимита |
| `MINE` | «Мина»: мина на клетке своего поля без корабля, по которой соперник ещё не стрелял; выстрел соперника в неё — результат MINE; нужна клетка, тратит выстрел из лимита |

### `BonusRejectionReason`

Причина, по которой платформа не применила бонус

| Значение | Смысл |
|---|---|
| `NOT_YOUR_TURN` | Не ход бота: ход соперника, партия ещё в расстановке или уже завершена |
| `BONUS_NOT_AVAILABLE` | Этого бонуса у бота в партии нет |
| `BONUS_LIMIT_REACHED` | Использования бонуса в партии кончились |
| `BONUS_ALREADY_ACTIVE` | Бонус уже действует: щит ещё не сработал или ход уже стал залпом |
| `INVALID_CELL` | Клетка не подходит бонусу: не указана или вне поля, а для мины ещё — с кораблём, уже обстрелянная соперником или с миной |

### `BotCommandRejectionReason`

Причина, по которой платформа отклонила команду бота

| Значение | Смысл |
|---|---|
| `UNKNOWN_MODE` | Режима с таким именем на платформе нет |
| `NO_RUNNING_MATCH` | У бота сейчас нет идущей партии: до первой партии или между партиями; во время торгов «Казино „Рояль“» партии ещё нет |
| `UNREADABLE_MESSAGE` | Сообщение не читается: не JSON или не JSON-объект |
| `UNKNOWN_COMMAND` | Поле type отсутствует или не называет известную команду |
| `INVALID_COMMAND` | Поля известной команды некорректны: отсутствуют, пустые, не того типа или вне диапазона |
| `UNKNOWN_BUILT_IN_BOT` | Встроенного бота с таким именем на платформе нет |

### `BuiltInBot`

Уровень встроенного бота платформы — соперника в тренировочных боях; имя значения — идентификатор в поле opponent команды CHANGE_MODE, в API и в журнале партии

| Значение | Смысл |

| `MEDIUM` | Средний уровень |
| `HARD` | Сложный уровень |

### `MatchEndReason`

Причина завершения партии

| Значение | Смысл |
|---|---|
| `FLEET_DESTROYED` | Все корабли одного из игроков потоплены |
| `TIME_LIMIT` | Вышло время партии; исход — по числу попаданий |
| `SHOT_LIMIT` | Оба игрока исчерпали лимит выстрелов; исход — по числу попаданий |
| `NO_PLACEMENT` | Техническое поражение: соперник не прислал корректную расстановку в окне расстановки |
| `NEITHER_PLACED` | Ни один игрок не прислал корректную расстановку в окне расстановки; победителя нет |
| `SPEEDRUN_FINISHED` | «Спидран» решён: побеждает потопивший флот за меньшее число выстрелов, при равном числе — ничья |

### `RejectionReason`

Причина, по которой движок отклонил расстановку или выстрел

| Значение | Смысл |
|---|---|
| `SHIP_NOT_STRAIGHT_LINE` | Корабль пуст, его клетки повторяются или не лежат на одной прямой подряд |
| `SHIP_OUT_OF_BOARD` | Клетка корабля за пределами поля |
| `FLEET_MISMATCH` | Длины кораблей не совпадают с составом флота из набора правил |
| `SHIPS_OVERLAP` | Клетка принадлежит двум кораблям |
| `SHIPS_TOUCH` | Корабли касаются стороной или углом |
| `PLACEMENT_ALREADY_ACCEPTED` | Расстановка этого игрока уже принята и окончательна |
| `NOT_YOUR_TURN` | Выстрел не в свой ход |
| `MATCH_FINISHED` | Партия уже завершена |
| `NO_PLACEMENT_IN_MATCH` | В этой партии расстановки нет: флот расставляет платформа |

### `RuleModifier`

Модификатор правил партии; в партии действует не больше одного

| Значение | Смысл |
|---|---|
| `DUEL` | «Дуэль»: ход переходит к сопернику после каждого выстрела, даже после попадания |
| `THREE_MUSKETEERS` | «Три мушкетёра»: в ходе несколько выстрелов (shotsPerTurn); промах тратит выстрел хода, попадание — нет |
| `SCHRODINGER_SHIP` | «Корабль Шрёдингера»: потопление не объявляется — вместо SUNK приходит HIT стрелявшему, владельцу корабля и в MATCH_SNAPSHOT |
| `HUNGER_GAMES` | «Голодные игры»: лимит выстрелов на игрока снижен (shotLimitPerPlayer), исход чаще решает число попаданий |
| `SPEEDRUN` | «Спидран»: флот не расставляется — оба стреляют по копиям одной расстановки платформы, каждый в своём темпе, выстрелы соперника не приходят; побеждает потопивший флот за меньшее число выстрелов |
| `BIRD_BOX` | «Птичий короб»: бот не видит действий соперника по своему полю — OPPONENT_SHOT и OPPONENT_BONUS_USED не приходят, в MATCH_SNAPSHOT нет выстрелов соперника |
| `OLD_SCHOOL` | «Олдскул»: обычные правила без бонусов |
| `CASINO_ROYALE` | «Казино „Рояль“»: модификатор партии выбирают закрытые ставки ботов до её начала — от BET_REQUESTED до BETTING_FINISHED |

### `ShotResult`

Результат принятого выстрела

| Значение | Смысл |
|---|---|
| `MISS` | Мимо: клетка без корабля, вне поля или уже обстрелянная этим игроком |
| `HIT` | Ранил: у корабля остались целые клетки |
| `SUNK` | Убил: подбита последняя целая клетка корабля |
| `DEFENDED` | Отбито щитом: попадание не засчитано, клетка осталась необстрелянной, ход перешёл к владельцу щита |
| `MINE` | Выстрел в мину: засчитан, клетка обстреляна, попаданием не считается; ход перешёл к владельцу мины, следующий ход стрелявшего пропускается |

### `TouchRule`

Правило касания кораблей при расстановке

| Значение | Смысл |
|---|---|
| `NO_TOUCHING_EVEN_DIAGONALLY` | Корабли не касаются друг друга ни стороной, ни углом |

### `TurnAfterHitRule`

Правило очерёдности хода после попадания

| Значение | Смысл |
|---|---|
| `SHOOTER_KEEPS_TURN` | После попадания или потопления ход остаётся у стрелявшего |
| `HIT_SPENDS_SHOT` | Попадание тратит выстрел хода, как промах: при одном выстреле за ход ход переходит после любого выстрела |

## Отказ в подключении

| Код | HTTP | Описание |
|---|---|---|
| `BOT_TOKEN_INVALID` | 401 | Подключение бота без действующего токена: токен не передан, не выпускался или перевыпущен |
| `BOT_BLOCKED` | 403 | Подключение заблокированного администратором бота с его действующим токеном |

## Закрытие соединения

| Код | Причина | Описание |
|---|---|---|
| 4001 | `TOKEN_REISSUED` | Команда перевыпустила токен, с которым открыто это соединение |
| 4002 | `CONNECTION_REPLACED` | Открыто новое соединение с этим токеном |
| 4003 | `DELIVERY_FAILED` | Сообщения боту не доставлены: очередь переполнена или отправка не уложилась в срок |
| 4004 | `BOT_BLOCKED` | Администратор заблокировал бота |
| 4005 | `BOT_DELETED` | Команда удалила бота, которому принадлежит это соединение |
| 4006 | `MESSAGE_RATE_EXCEEDED` | Бот прислал больше сообщений, чем позволяет лимит частоты; подключиться снова можно сразу |
| 4007 | `PLATFORM_UPDATING` | Платформа обновляется: подключитесь снова |
| 1009 | `None` | Сообщение бота длиннее 8 КиБ: сервер его не принимает и закрывает соединение |
| 1011 | `None` | Необработанная ошибка платформы при выполнении команды бота |
