# Нейро Мугивары · battleShips

Клиент команды для [турнирной платформы](https://hackathon.no-offence.ru/).
Python 3.12+, WebSocket + JSON. Общая программа, отдельный процесс и токен для каждого бота.

## Данные соперника

Оболочка передаёт стратегии `state.opponent_info`: ID бота, ключ для статистики,
наблюдаемый Elo, источник и время получения. Для ботов команд рейтинг запрашивается
автоматически через публичную статистику; при ошибке или задержке он равен `None`.
У встроенных ботов доступны ключи `builtin:EASY|MEDIUM|HARD`; их Elo требует отдельного
сборщика и необязательного `--opponent-ratings-file`. После восстановления через
`MATCH_SNAPSHOT` личность соперника может быть неизвестна.
Интерфейс для выбора стратегии, расстановки и сбора статистики описан в
[контракте стратегии](docs/strategy-contract.md#соперник-интерфейс-для-бориса).

## Что уже работает

- Подключение с `Authorization: Bearer ...`, выбор режима, последовательная обработка запросов сервера.
- Расстановка, выстрелы, завершение партии и следующая партия на том же соединении.
- Восстановление из `MATCH_SNAPSHOT`, повторное подключение с задержкой.
- Проверка ответов стратегии и запасной ход. Стратегия работает в отдельном завершаемом процессе.
- Обработка `HIT`, `SUNK`, `MISS`, `DEFENDED`, `MINE`; неизвестные сообщения не роняют клиент.
- Спидран без расстановки; остальные режимы используют параметры и события своей партии.
- Локальный журнал JSONL без токена. Платные бонусы выключены по умолчанию, ставки не делаются.

Встроенная `BaselineStrategy` — простая заглушка: случайный поиск и добивание.
Это основа интеграции для подключения стратегии Бориса, не финальный турнирный алгоритм.

## Установка и проверка

Из корня репозитория в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -v
```

Если команда `py` отсутствует, используйте установленный Python 3.12+ через `python`.
Linux/macOS: `python3 -m venv .venv`, затем `.venv/bin/python` вместо пути Windows.

Тесты работают без токена и без обращения к турниру. Локальный сервер проводит полные партии на поле 10×10,
принудительно разрывает соединение и отдаёт снимок состояния. Также проверяются зависшая и падающая стратегии.

## Подключение к турниру

```powershell
Copy-Item .env.example .env
```

Впишите токен **своего конкретного бота** в локальный `.env`, затем:

```powershell
.\.venv\Scripts\python.exe -m battleships --mode TRAINING --opponent EASY --stop-after 1
```

Тренировочные партии тоже меняют Elo. На уровне платформы новое соединение изначально находится в `RANKING`:
клиент сразу отправляет `CHANGE_MODE`, но если матч уже начался, он доигрывается в прежнем режиме.
Поэтому команда `--mode TRAINING` не гарантирует, что уже назначенный первый матч будет тренировочным.

Рейтинговая непрерывная игра:

```powershell
.\.venv\Scripts\python.exe -m battleships --mode RANKING
```

Остановить: `Ctrl+C`. Если партия уже началась, сервер продолжит её без отключившегося бота.
`--stop-after 1` завершает клиент после получения результата одной партии.

## Три бота

Создайте локальные `.env.bot1`, `.env.bot2`, `.env.bot3` с разными токенами. Откройте три терминала:

```powershell
.\.venv\Scripts\python.exe -m battleships --env-file .env.bot1 --log-dir logs/bot1 --mode TRAINING
.\.venv\Scripts\python.exe -m battleships --env-file .env.bot2 --log-dir logs/bot2 --mode TRAINING
.\.venv\Scripts\python.exe -m battleships --env-file .env.bot3 --log-dir logs/bot3 --mode TRAINING
```

Каждая строка запускается в своём терминале. Переменные окружения имеют приоритет над `.env`:
если `BATTLESHIPS_TOKEN` уже задан в окружении, он перекроет токен из любого выбранного файла.
Можно использовать отдельные переменные через `--token-env BATTLESHIPS_TOKEN_1` и т. п.

Один токен нельзя одновременно запускать у двух участников. При `CONNECTION_REPLACED` клиент останавливается,
чтобы два процесса не переподключались и не отключали друг друга бесконечно.

## Подключение стратегии Бориса

Контракт описан в [docs/strategy-contract.md](docs/strategy-contract.md).

```powershell
.\.venv\Scripts\python.exe -m battleships --strategy strategy.boris:BorisStrategy
```

Класс без обязательных аргументов конструктора реализует:

```python
def place_ships(self, rules: Rules) -> list[list[Cell]]: ...
def choose_action(self, state: GameState, time_budget_ms: int) -> Action: ...
```

Путь `strategy.boris:BorisStrategy` — пример: соответствующий модуль должна добавить команда.
По умолчанию используется существующий `battleships.strategy:BaselineStrategy`.

## Зоны ответственности

| Зона | Ответственный | Файлы |
|---|---|---|
| Подключение, состояние, защита от сбоев, запуск | Музроб | `battleships/client.py`, `worker.py`, `__main__.py` |
| Общий интерфейс | Музроб + Борис | `battleships/model.py`, `docs/strategy-contract.md` |
| Сильная стратегия, расстановка, симулятор | Борис | Свой модуль стратегии и симулятор; baseline остаётся резервным |
| Правила, приоритеты, проверка версий, выпуск | Диана | Сценарии, результаты сравнений, проверка кандидата на выпуск |

Ветки участников объединяем после тестов. В `main` — проверенная версия.
Перед изменением контракта согласуем его с владельцами обоих модулей.

## Границы первой версии

- Проверено на локальном сервере по опубликованному протоколу. Реальное подключение и сетевые задержки турнира ещё нужно проверить.
- Цель расчёта — 150 мс (`--budget-ms`), резерв до серверного лимита — 250 мс (`--reserve-ms`). Это настройки, не гарантия реального времени.
- Снимок сервера не содержит дедлайна текущего хода: после восстановления ждём `TURN_REQUESTED`.
- В снимке нет истории результатов сонара/расстояния и идентификатора соперника. Они не восстанавливаются из предыдущего процесса; стратегия должна переносить отсутствие этих данных.
- Неведомое новое правило касания нельзя безопасно угадать. Текущий валидатор расстановки поддерживает опубликованное `NO_TOUCHING_EVEN_DIAGONALLY`.
- Бонусы требуют явного `--allow-bonuses` и стратегии, умеющей оценивать их стоимость. Baseline их не использует. `CASINO_ROYALE` обрабатывается отказом от ставки; выбранные правила принимаются из `MATCH_STARTED`.
- Среднее число ходов не равно доле побед: для выпуска сравниваем стратегии по режимам, победам, попаданиям, задержкам и тайм-аутам.
